| ~~K11~~ ✅ **RESOLVED** — **Embedded Postgres cannot start in this container**, so all DB-backed tests self-skip. Root cause: `initdb` refuses to run as root and the container runs as root. | K10 | **An apostrophe in a plugin migration comment breaks the host validator.** `stripSqlForKeywordScan` strips quoted literals *before* stripping `--` comments, so a lone `'` in a comment opens a phantom string that swallows the SQL after it. | K9 | **Agents cannot call plugin tools.** `GET /api/plugins/tools` and `POST /api/plugins/tools/execute` both call `assertBoardOrgAccess(req)`, which throws `forbidden` for any `actor.type === "agent"`. Tools are still declared for parity and forward-compatibility. Opening the tool routes to agents is a separate, auth-boundary change — not part of slice 1. |
